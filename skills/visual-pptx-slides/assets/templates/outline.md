# 構成案: 〔デッキ名〕

- 目的: 〔この資料で聞き手に何をしてほしいか。1文〕
- 聞き手: 〔誰が・何を知っている前提か〕
- 形式: 〔発表 N 分 / 配布のみ〕 ・ 枚数: 〔N 枚〕 ・ theme: 〔default / corporate〕
- 色の意味: 藍 = 〔〕 / 碧 = 〔〕 / 山吹 = 〔〕 / 朱 = ここが変わった
- 素材: 〔ユーザーから受け取った資料・URL・数字の出所〕
- 未確認事項: 〔裏取りできていない数字・日付。無ければ「なし」〕

## タイトル読み（タイトルだけを順に並べる）

1. 〔表紙タイトル〕
2. 〔結論文〕
3. 〔…〕

- タイトル: 〔…[[変化点]]…〕

### 2. 〔キッカー（章名）〕（P-〔ID〕）

- 補足: 〔右パネル・注記・概念図タグの有無〕
- 行動帯: 〔今やる1手の文 / なし〕
- 出典: 〔〕
- ノート: 〔話す内容（任意）〕
