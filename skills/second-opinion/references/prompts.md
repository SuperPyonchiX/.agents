# 質問文テンプレート

SKILL.md の手順4（ラウンド0）と手順5（反論ラウンド）で質問文を書くときに読む。`{...}` を埋めてスクラッチパッドに `.md` で保存し、選んだ相談スクリプトの `--prompt-file` に渡す。

## ラウンド0（独立回答）

実行中のエージェント自身の見解は**書かない**。書くと相手が引きずられ、独立した意見でなくなる。

```markdown
次の判断について、あなた自身の見解を求めます。

## 問い
{問い。選択肢があれば列挙}

## 前提・制約
{判断に効く前提。機密チェック済みのものだけ}

## 参照してよいもの
{読ませるファイルやディレクトリ。無ければ「なし（一般論で答える）」}
相談対象のファイルは読み取りだけにしてください。必要な読解・検索・検証には通常のツールとMCPを使えます。
{必要な資料の抜粋と出典パス・行番号}
別の生成AIへの相談・委任・サブエージェントの利用は禁止します。

## 回答の形式
1. 結論（1〜2文）
2. 根拠（箇条書き。ファイルを根拠にしたらパスを添える）
3. 確度（高・中・低）と、結論が変わる条件
4. 見落とされやすい論点
```

## 反論ラウンド（ラウンド1〜2）

相違点だけを送る。一致点は送らない。**同意を誘導しない**。「Claude はこう考えるが正しいですよね」ではなく、両方の根拠を並べて判定を求める。

```markdown
あなたの回答と、別の検討者（実行中のエージェント）の見解が次の点で分かれました。
各論点について、立場を維持するか変えるかを理由つきで答えてください。
相手の根拠に誤りがあれば具体的に指摘してください。安易に合わせる必要はありません。

## 論点{n}: {論点名}
- あなたの結論: {相手の結論の要約}
- 検討者の結論: {検討者の結論}
- 検討者の根拠: {根拠。ファイルならパス}

## 回答の形式（論点ごと）
- 判定: 維持 / 変更 / 部分的に変更
- 理由（相手の根拠のどこを受け入れ、どこを受け入れないか）
- この論点を決着させるのに足りない情報があれば、それ
```
