# 成果物ファイルを選択状態で開く

深い階層に出力したファイルを、ユーザーが探しに行かずに済むようにする。やることは `scripts/reveal.py` を1回呼ぶだけで、判断が要るのは「開くべき場面か」だけ。

## 開く場面・開かない場面

| 場面 | 扱い |
|---|---|
| ユーザーが開くよう頼んだ | 開く |
| PDF・docx・xlsx・pptx・画像・HTML など、**手元のアプリで開いて確かめる成果物**を新しく作った | 最終報告の直前に開く |
| ソースコードや設定ファイルを編集した | 開かない。エディタで見るものなので差分の報告で足りる |
| 作業途中の中間ファイル・一時ファイル | 開かない |
| 同じ応答の中で既に開いた | 開き直さない |
| リモート実行（SSH・クラウドセッション・別端末から操作中） | 開かない。パスを示す。ファイルを送る仕組みがある環境ならそれを使う |

どれにも当てはまらず迷ったら、開かずにパスを示し「エクスプローラーで開きますか」と一言添える。

## 手順

1. 開く対象のパスを確定する。**実際に書き出したパスを使う。** 相対パスでよい。
2. スクリプトを実行する。

   ```
   python scripts/reveal.py <path> [<path> ...]
   ```

3. 終了コードで分岐する。

   | 終了コード | 意味 | 次の動き |
   |---|---|---|
   | 0 | 開いた | 報告にパスを1行添える |
   | 1 | パスが存在しない | 書き出しに失敗しているか、パスの取り違え。**別の場所を推測で開き直さない。** 生成処理の出力を見直す |
   | 2 | 引数の指定ミス | 引数を直して1回だけ再実行する |
   | 3 | GUI が使えない環境 | 開けなかった旨とパスを報告する。再試行しない |

**完了条件**: 終了コード 0 でファイルマネージャーが開いたか、0 以外のときに理由とパスをユーザーに伝えたこと。

## 禁止事項

- `explorer` / `open` を直接組み立てて叩くこと。Windows の `/select,` はパスの引用符の扱いが崩れやすく、シェルごとに挙動が違う。必ずスクリプトを通す
- 存在しないパスを、近い名前のファイルやフォルダに置き換えて開くこと
- 同じフォルダのファイルを1件ずつ開いてウィンドウを並べること。スクリプトが先頭1件に絞る

## スクリプト

`scripts/reveal.py` — 依存は標準ライブラリのみ。

| 引数 | 意味 |
|---|---|
| `<path> ...` | 開くファイルまたはディレクトリ。ディレクトリはそのものを開く |
| `--dry-run` | 開かずに、実行するコマンドだけ表示する。動作確認用 |

| OS | 実際の動作 |
|---|---|
| Windows | `explorer /select,"<path>"` |
| WSL | `wslpath -w` で変換して `explorer.exe /select,` |
| macOS | `open -R <path>` |
| Linux | D-Bus の FileManager1.ShowItems。無ければ親フォルダを `xdg-open` |

同じフォルダのファイルが複数渡されたら、先頭1件だけ選択して開き、残りは `SAME-FOLDER` として表示する。終了コードは手順3の表のとおり。
