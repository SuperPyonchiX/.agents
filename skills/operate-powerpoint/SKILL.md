# PowerPoint の操作

python-pptx で .pptx を読み書きし、配置はスクリプトで検査し、見た目は画像にして全スライドを確かめる。
失敗しやすいのは4点。既定のテンプレートが 4:3 で和文フォントも効かない、python-pptx は文字の量に合わせて縮小しないので文字が枠からあふれる、テンプレートのレイアウトを使わず座標を目分量で置いて重なる、1枚に情報を詰め込みすぎる。

## 手順

### 1. 中身を把握する

```
python scripts/inspect_pptx.py <pptx> [--layouts] [--slides 1-3] [--check]
```

スライドの大きさ、スライドごとのレイアウト名・図形（プレースホルダの番号・位置・文字）・ノートが出る。`--layouts` はテンプレートのレイアウトと各枠の位置、`--check` はスライド外へのはみ出しと文字を持つ図形どうしの重なりを出す。

`.ppt` は読めない（終了コード2）。ユーザーの了承を得て PowerPoint か LibreOffice で `.pptx` に変換してから扱う。

### 2. 構成を決めてから作る

スライドを作る前に、1枚1行で構成（各スライドのタイトルと伝えること）を書き出してユーザーに見せる。直すだけの依頼なら省く。

構成の決まり:

- 1枚で伝えることは1つ。タイトルはその結論を文で書く（「現状」ではなく「不具合は 3 件に減った」）
- 箇条書きは1枚5行まで、1行は全角30字程度まで。説明しきれない分はノートに書く
- 本文の文字は 18pt を下回らせない。入らなければ文字を減らすか、スライドを分ける

作り方:

| 状況 | やり方 |
|---|---|
| テンプレート（社内様式）がある | `Presentation(テンプレート)` で開き、`--layouts` で選んだレイアウトから `add_slide` する。フォント・色・大きさは様式に任せ、上書きしない。見本スライドは使い終わったら消す |
| テンプレートが無い | `references/python-pptx-helpers.md` の `widen_to_16x9()` で 16:9 にしてから作り、最後に `set_ja_font()` を当てる |
| 既存の資料を直す | 原本は変えず別名で保存する。直すスライドの図形を `inspect_pptx.py --slides N` で確かめ、名前か番号で指定して書き換える |
| どれにも当てはまらない（アニメーション・SmartArt・埋め込み動画など python-pptx が扱わない要素） | 止まり、扱えない要素であることをユーザーに伝え、PowerPoint での手作業か作り直しかを確認する |

スライドの削除・並べ替え、和文フォントの指定、つまずきやすい点は `references/python-pptx-helpers.md` にある。作り始める前に一度読む。

### 3. 検査して見た目を確かめる

```
python scripts/inspect_pptx.py <pptx> --check
python "<operate-pdf-dir>/scripts/to_pdf.py" <pptx> --outdir <作業フォルダ>
python "<operate-pdf-dir>/scripts/pdf_to_png.py" <作業フォルダ>/<名前>.pdf
```

`to_pdf.py` と `pdf_to_png.py` は`operate-pdf` スキルのもの。

```
for 周回 in 1..3:
    --check で はみ出し・重なり を出す
    全スライドの画像を読み、文字のあふれ・欠け・小さすぎる文字・和文の化け・空のプレースホルダを一覧にする
    if 両方 0件: break
    該当スライドの該当図形だけを直す（文字を減らす > 枠を広げる > スライドを分ける の順に検討する）
else:
    3周で直らなければ、残っている問題と試したことを報告する。直ったとは言わない
```

`--check` は図形の枠の位置しか見ない。文字が枠に収まっているかは画像でしか分からないので、画像の確認を省かない。

## 完了条件

- `inspect_pptx.py --check` が終了コード0（意図して重ねた図形がある場合は、その組をユーザーに伝えたこと）
- 全スライドの画像に、文字のあふれ・化け・空のプレースホルダが無いこと。変換エンジンが無く確かめられなかったら（`to_pdf.py` が終了コード3）、その旨をユーザーに伝えたこと

## 禁止事項

- 原本を上書きすること
- 文字があふれたとき、フォントを 18pt 未満に下げて押し込むこと
- テンプレートがあるのに、フォント・配色・ロゴの位置を独自に変えること
- 画像を見ずに「スライドを作成しました」と報告すること

## スクリプト

依存は `python-pptx`（`pip install python-pptx`）。無ければ終了コード2で止まるので、導入をユーザーに確認する。

`scripts/inspect_pptx.py` の終了コード:

| コード | 意味 |
|---|---|
| 0 | 出力した（`--check` では問題なし） |
| 1 | 開けない、または `--check` ではみ出し・重なりが見つかった |
| 2 | 引数の指定ミス、入力が無い、`.ppt`、または依存不足 |

位置は mm で出る。1 mm 以下のはみ出し・重なりは無視する。

PDF 化と画像化は `operate-pdf` スキルの `to_pdf.py` と `pdf_to_png.py`（要 `pypdfium2` `Pillow`）を使う。

## PDF変換の依存先

このスキルのzipにoperate-pdfは含まれない。利用可能なスキル一覧からoperate-pdfの実体パスを解決し、`<operate-pdf-dir>`を置き換える。未導入なら、利用可能なOfficeのPDF出力と画像表示で同じ観点を確認する。変換・画像表示のどちらかが使えなければ、構造検査までの結果と「見た目未確認」を明示し、完成扱いにしない。確認済みとするために必要な依存先を案内する。
