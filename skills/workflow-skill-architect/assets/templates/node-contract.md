# ノード契約テンプレート

各ノードをこの形式で定義する。埋まらない欄があるなら、そのノードはまだ設計できていない。

## ノード: <node-name>

- **目的**: <1行。何を達成するか>
- **依存**: <先行ノード名。なければ「—」>
- **入力**: <パスと形式。会話の文脈に依存しないこと>
- **出力**: <パスと形式。スキーマまたは実例を添える>
- **前提**: <この条件が崩れていたら実行してはいけない、というもの>
- **やらないこと**: <範囲外。サブエージェントに渡す場合は必須>
- **失敗時**: <status に何を書くか、後続を止めるのか続けるのか>
- **迷ったとき**: <ユーザーに聞くのか、仮置きして issues に記録するのか>

## 出力の最小実例

```json
{
  "node": "<node-name>",
  "status": "ok",
  "summary": "<3行以内。後続はまずここだけ読む>",
  "items": [],
  "issues": []
}
```
