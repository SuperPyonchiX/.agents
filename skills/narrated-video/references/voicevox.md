# VOICEVOX の準備と台本の書き方

N0 でエンジンに接続できないとき、N1 で台本を書くときに読む。

## エンジンの起動

`voicevox_tts.py` は VOICEVOX エンジンの HTTP API（既定 `http://127.0.0.1:50021`）を呼ぶだけで、起動はしない。次のどちらかで起動しておく。

| 方法 | やり方 | 向いている場面 |
|---|---|---|
| アプリ | VOICEVOX を普通に起動する。起動中はエンジンも動いている | 人が横で作業しているとき |
| エンジン単体 | インストール先の `vv-engine/run.exe --host 127.0.0.1 --port 50021` をバックグラウンドで起動する | 画面を出したくないとき |

- インストール先は入れ方で変わる。winget（`winget install HiroshibaKazuyuki.VOICEVOX.CPU`）で入れた場合は `%LOCALAPPDATA%\Microsoft\WinGet\Packages\HiroshibaKazuyuki.VOICEVOX.CPU_*\VOICEVOX\vv-engine\run.exe`。見つからなければ `VOICEVOX.exe` の隣の `vv-engine` を探す
- 起動には十数秒かかる。`curl http://127.0.0.1:50021/version` が版数を返したら使える
- エンジン単体を起動したら、作業後に止める（プロセスを終了する）

## 話者の選び方

`python scripts/voicevox_tts.py --list-speakers` で `キャラ名 [style id:スタイル名, ...]` が出る。scenes.json の `speaker` には **style id**（数字）を書く。

- 解説動画の既定は、聞き取りやすく癖の少ないノーマル系にする（例: ずんだもん ノーマル `3`、四国めたん ノーマル `2`）
- ユーザーが指定しなければ、候補を2〜3人挙げて選んでもらう。**勝手に決めて公開用の動画を作らない**

## 利用規約とクレジット

- VOICEVOX で作った音声を使う動画には **`VOICEVOX:キャラ名` のクレジット表記が必要**。雛形は最後にクレジット画面を付け、`narration.json` の `credit` をそのまま表示する。動画の説明欄に書くなら、クレジット画面を外してもよい
- キャラクターごとに個別の利用規約がある（商用の可否・禁止用途など）。**公開・配布する前に、使ったキャラの規約を公式サイトで確認するようユーザーに伝える**。手元で見るだけなら確認は不要

## 台本の書き方

1シーン = 1つの画面 = 1〜2文。1シーンが10秒を超えたら分ける（画面が変わらない時間が長いと単調になる）。

| 書くもの | ルール |
|---|---|
| `text`（読み上げ） | 英単語・略語・記号はカタカナかひらがなで書く（`Claude` → クロード、`SKILL.md` → スキルエムディー、`C++` → シープラスプラス）。数字は読み方が割れるなら仮名にする |
| `subtitle`（字幕） | 画面に出す正しい表記。`text` と同じでよければ省略する |
| 間 | 読点「、」で短い間、句点「。」で長めの間。シーン間の無音は `pauseAfter`（秒） |

読み間違いは N3 で音声を聞かないと分からない。ユーザーに聞いてもらい、指摘されたシーンだけ `text` を直して `--only` で作り直す。
