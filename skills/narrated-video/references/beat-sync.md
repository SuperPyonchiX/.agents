# ビートに合わせた演出

N0 で種類を「告知・CM」にしたとき、N2 の後に timeline.py を `--bpm` 付きで回す前に読む。

## 考え方

告知・CM はシーンの切り替えと画面の動きを拍に合わせると、それだけで「編集された動画」に見える。
`timeline.py --bpm` はシーンの尺を拍か小節の長さで切り上げ、開始を拍の頭にそろえる。ナレーションは拍の頭から始まり、余った時間は無音で埋まる。

## BPM とパターンの選び方

| 動画の雰囲気 | BPM | `--pattern` | `--snap` |
|---|---|---|---|
| 勢いのある告知・CM | 120〜128 | `four`（四つ打ち） | `beat` |
| テンション高めの解説 | 100〜110 | `break` | `bar` |
| 落ち着いた紹介 | 80〜90 | `half`（ハーフタイム） | `bar` |

- `--snap bar` は1シーンが小節単位になる。区切りがはっきりするが、尺が伸びやすい。15秒程度の短い動画は `beat`
- 手持ちの曲を使う場合は `--bgm` を付けずに、その曲の BPM を `--bpm` に渡す。曲の頭が拍の頭になるよう、曲の冒頭の無音を切ってから `public/bgm/` に置き、雛形の `BGM_FILE` に書く
- `--bgm` で作るドラムは仮の BGM。公開する動画では、利用条件を確かめた曲に差し替えるかをユーザーに聞く

## 画面を拍に合わせる

雛形の `useBeat()` を各シーンの画面の中で呼ぶ。返り値は `{ index, since, pulse, downbeat }`。

| やりたいこと | 書き方 |
|---|---|
| 拍ごとに弾ませる | `const { pulse } = useBeat(); <div style={{ transform: \`scale(${1 + 0.06 * pulse})\` }}>` |
| 小節の頭で光らせる | `const { pulse, downbeat } = useBeat(10); opacity: downbeat ? pulse : 0` |
| 拍ごとに要素を1つずつ出す | `const { index } = useBeat(); items.slice(0, index - firstIndex + 1)`（`firstIndex` はシーン開始時の index） |

- 全部の要素を拍で動かさない。弾ませるのは見出しか1要素にとどめ、他は静止させる
- 字幕は拍で動かさない（読めなくなる）
- アニメーションの書き方そのもの（`spring`・`interpolate`・トランジション）は `remotion-best-practices` に従う

## 検証での見方

N4 の静止画は、シーンの中央フレームに加えて**シーンの開始フレーム**も撮る（`timeline.py` の表の「開始」）。開始フレームで前のシーンの要素が残っていないか、拍の頭で画面が切り替わっているかを見る。リズムが合っているかは静止画では分からないので、N5 の試聴で聞いてもらう。
