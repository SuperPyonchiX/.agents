# AGENTS.md

このフォルダは私の「第二の脳」。調べ物の結果と、試して分かったことを Markdown で溜める。

## 外に出さない

- ここの内容を社外のサービスへ送らない（Web 検索の語句、NotebookLM などへのアップロード、外部の AI への貼り付けを含む）。必要なときは先に確認する
- git の remote を追加しない

## フォルダの使い分け

| フォルダ | 入れるもの |
|---|---|
| `00_受信箱` | 分類に迷うもの、思いつきのメモ。判断がつかないときの既定の置き場 |
| `04_ノウハウ` | 自分で試して分かったこと（ツールの設定、仕事の手順、ハマりどころ）。1テーマ1ファイル、既存があれば追記 |
| `リサーチ` | 調べ物の結果。`YYYY-MM-DD_テーマ名.md`。結論・根拠・出典の3点を必ず書き、保存先のパスを伝える |

- 深い階層は作らない。迷ったら `00_受信箱`
- 書く前に関連ファイルを検索し、あれば本文でファイル名に触れる
