## 目的

〔何を実現するか。1〜3文〕

## 範囲外

- 〔やらないこと。無ければ「なし」〕

## 受け入れ条件

- [ ] 〔判定できる文。例: CSV に空行があっても取り込みが止まらない〕

## 検証コマンド

| 種類 | コマンド |
|---|---|
| テスト | 〔例: `pytest -q`〕 |
| lint・型検査 | 〔例: `ruff check . && mypy src`。無ければ「なし」〕 |
| ビルド | 〔無ければ「なし」〕 |
| 起動確認 | 〔例: `python -m app --help` が終了コード 0。無ければ「なし」〕 |

## タスク

状態は 未着手 / 進行中 / 完了 / 保留 / 中止 のどれか。進行中は同時に1件まで。

「変更ファイル」には着手時に変える予定のファイルを書き、終えたら実際に変えたものに直す。再開時はこの列と git の状態を突き合わせる。

| ID | タスク | 完了条件 | 状態 | 変更ファイル | 証拠 | コミット |
|---|---|---|---|---|---|---|
| 〔T1〕 | 〔差分を一度に読める単位〕 | 〔例: `test_parse_empty_line` が通る〕 | 未着手 | | | なし |
