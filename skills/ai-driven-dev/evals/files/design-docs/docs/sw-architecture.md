# 温度監視ユニット SW アーキテクチャ設計書（抜粋）

## コンポーネント

| ID | 名前 | 責務 |
|---|---|---|
| CMP-01 | SensorReader | 温度センサを 100 ms 周期で読み、生値を出す |
| CMP-02 | Filter | 生値を移動平均で平滑化する |
| CMP-03 | AlarmJudge | 平滑値がしきい値を超えたら警報を出す |
| CMP-04 | CanSender | 平滑値と警報を CAN で送る |

## コンポーネント間の流れ

- CMP-01 → CMP-02: 生値（0.1 ℃単位、int16）
- CMP-02 → CMP-03: 平滑値
- CMP-02 → CMP-04: 平滑値
- CMP-03 → CMP-04: 警報（あり / なし）
