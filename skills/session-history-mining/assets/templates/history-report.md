# セッション履歴の棚卸し（YYYY-MM-DD）

## 集計の範囲

| 項目 | 値 |
|---|---|
| 期間 | YYYY-MM-DD 〜 YYYY-MM-DD（直近 N 日） |
| 読んだ履歴 | Claude Code history.jsonl / Codex sessions（読めなかったものはここに書く） |
| 発話 / セッション | N 件 / N 件 |
| 画像つき発話 | N 件 |
| 指摘候補（機械抽出） | N 件（うち指摘と判断 N 件） |

## 判定表

| # | パターン | 根拠（セッション数・発話例） | 処置 | 理由 |
|---|---|---|---|---|
| P1 | 例: 画像を添えて図の崩れを直させる | 4セッション / 「このシーケンスもおかしい」 | 既存スキルへ追記: ui-visual-verify | 既存の台帳運用で足りるが、図エディタの再撮影手順が無い |

処置は次のどれか1つ: 既存スキルで足りる（発火語を足す）/ 既存スキルへ追記 / 常時ルールへ（AGENTS.md・CLAUDE.md・メモリ）/ 新スキル候補 / 見送り

## 新スキル候補

| 候補名 | 何をするか | 根拠のセッション数 | 既存スキルに足せない理由 |
|---|---|---|---|

## 常時ルール候補

| 置き場所 | 追記する文（案） | 元になった指摘 |
|---|---|---|

## 未判定

判定上限を超えて残したパターン。件数と一覧。無ければ「なし」。
