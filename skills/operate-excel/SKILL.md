# Excel ブックの操作

openpyxl でブックを読み書きし、数式は表計算ソフトに再計算させて検査し、見た目は PDF にして確かめる。
失敗しやすいのは4点。openpyxl は数式を計算しないので値の誤りに気づかない、既存ブックを開いて保存すると図形やマクロが消える、Python で計算した結果を数値で書き込んで数式の無い表にしてしまう、`data_only=True` で開いたブックを保存して数式を全部消す。

## 手順

### 1. 構造を把握する

既存のブックは、中身を読む前に構造だけ出す。

```
python scripts/inspect_xlsx.py <xlsx> [--sheet NAME] [--rows 10]
```

シート一覧・使用範囲・数式の数・結合セル・先頭数行のプレビューと、**openpyxl で保存すると失われる要素**（マクロ・図形・スライサー・フォームコントロールなど）が出る。

- 読むだけなら、必要なシートと範囲を絞って読む。数千行を会話に載せない。集計は Python（pandas があれば `read_excel`）で行い、結果だけを示す
- `.xls` は openpyxl で読めない（終了コード2）。ユーザーの了承を得て Excel か LibreOffice で `.xlsx` に変換してから扱う

### 2. 作る・直す

**新しく作るとき**

- 計算は数式で書く。合計・比率・前年比を Python で計算して数値を入れない。前提値（単価・税率など）はセルに置き、数式から参照する
- 数値は数値型で書く。`"1,200"` のような文字列にせず、`number_format`（`#,##0`、`0.0%`、`yyyy/mm/dd`）で見せ方を決める
- フォントを明示する。openpyxl の既定は Calibri で、和文は環境ごとの代替フォントになる。業務文書なら `游ゴシック` か `メイリオ` を全セルに指定する
- 列幅を指定する。openpyxl は自動調整しない。和文1文字はおよそ幅2で見積もる
- 見出し行は `freeze_panes` で固定し、一覧表なら `auto_filter` を付ける。印刷するものは用紙（A4）・向き・`fitToWidth` を設定する
- `XLOOKUP` `FILTER` `UNIQUE` `LET` など新しい関数は使わない。openpyxl では `_xlfn.` 接頭辞が要り、古い Excel と LibreOffice では `#NAME?` になる。`INDEX`/`MATCH`・`SUMIFS` で書く
- 保存前に `wb.calculation.fullCalcOnLoad = True` を設定する。Excel で開いたときに再計算させるため

**既存のブックを直すとき**

1. 手順1の「失われる要素」に何か出たら、openpyxl で保存する前に止まり、何が消えるかをユーザーに伝えて進め方を確認する
2. 原本は変えず、コピーに対して書く
3. `load_workbook(path)` で開く。`.xlsm` は `keep_vba=True` を付け、拡張子を変えずに保存する
4. 書くのは頼まれたセルだけ。既存の書式（フォント・表示形式・罫線）に合わせ、行や列の挿入は数式の参照ずれを確かめてから行う
5. 編集後に差分を出し、変わったセルが意図した範囲と一致するかを確かめる

   ```
   python scripts/diff_xlsx.py <原本> <編集後>
   ```

   意図していないセル・結合・シートの変化が出たら、その原因を直してから先へ進む。

### 3. 数式を検査する

数式を1つでも書いたら必ず実行する。

```
python scripts/recalc_check.py <xlsx>
```

ブックのコピーを LibreOffice か Excel で再計算し、エラーのセルを JSON で返す。元のファイルは変えない。

```
for 周回 in 1..3:
    recalc_check.py を実行する
    if 終了コード 0: break
    errors の各セルについて、参照範囲・0除算・名前の綴り・関数の対応を確かめ、その数式だけを直す
    uncalculated が 0 でなければ再計算が効いていない。--engine を切り替えて試す
else:
    3周で消えなければ、残っているセルと原因の見立てを報告する。直ったとは言わない
```

終了コード0は「エラーが出ていない」という意味でしかない。合計が合っているか、参照先がずれていないかは、主要な数式を2〜3個選んで手で検算する。

### 4. 見た目を確かめる（印刷・配布するもの）

レイアウトが意味を持つブック（帳票・印刷物・人に配る表）は、PDF にして画像で見る。隣の `operate-pdf` スキルのスクリプトを使う（パスはこのスキルのディレクトリからの相対）。

```
python ../operate-pdf/scripts/to_pdf.py <xlsx> --outdir <作業フォルダ>
python ../operate-pdf/scripts/pdf_to_png.py <作業フォルダ>/<名前>.pdf
```

列幅不足の `###`、ページからのはみ出し、改ページ位置の崩れを見て直す。直し方と周回の上限は `operate-pdf` の「見た目の確認ループ」に従う。

## 完了条件

- `recalc_check.py` が終了コード0。エンジンが無く終了コード3なら、数式を検査できていないことをユーザーに伝えたこと
- 既存ブックの編集では、`diff_xlsx.py` の差分が意図した変更だけであること
- 印刷・配布するブックでは、ページ画像に崩れが無いこと

## 禁止事項

- `data_only=True` で開いたブックを保存すること。数式がすべて値に置き換わる
- `IFERROR` でエラーを空欄や0に置き換えて `recalc_check.py` を通すこと。エラーの原因を直す
- 原本を直接上書きすること
- 「失われる要素」があるブックを、ユーザーに伝えずに openpyxl で保存すること

## スクリプト

すべて `--help` で引数が見られる。依存は `openpyxl`（`pip install openpyxl`）。無ければ終了コード2で止まるので、導入をユーザーに確認する。

| スクリプト | 用途 | 終了コード |
|---|---|---|
| `scripts/inspect_xlsx.py` | 構造と先頭数行のプレビュー、失われる要素の検出 | 0 出力した / 1 開けない / 2 引数ミス・非対応形式・依存不足 |
| `scripts/recalc_check.py` | コピーを再計算してエラーのセルを JSON で返す | 0 エラーなし / 1 エラーあり・未計算あり / 2 引数ミス・依存不足 / 3 エンジンが無い・再計算失敗 |
| `scripts/diff_xlsx.py` | 編集前後の値・書式・結合・シート構成の差分 | 0 差分なし / 1 差分あり（一覧を確かめる） / 2 引数ミス・依存不足 |

`recalc_check.py` の再計算エンジンは `--engine auto`（既定）で、LibreOffice があればそれを、無ければ Windows の MS Excel を使う。`--write-back` を付けると Excel で元のファイル自体を再計算して保存する（計算結果を読む別のプログラムに渡すとき用。Windows の Excel のみ）。

PDF 化と画像化は `operate-pdf` スキルの `to_pdf.py` と `pdf_to_png.py`（要 `pypdfium2` `Pillow`）を使う。
