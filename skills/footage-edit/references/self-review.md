# 自己検査のチェックリスト（目で見る項目）

E6 で `check.py --sheet` の画像を見るときに読む。機械で決まる項目（音量・無音・黒画面・字幕の文字数と時間）は
`check.py` が判定済みなので、ここでは**機械では決まらない項目**だけを当てる。

結果は `edit/review.md` に1行1件で書く。書式:

```
| # | 対象 | 項目 | 判定 | 直し方 |
|---|---|---|---|---|
| 1 | カット c004 | B-2 顔が切れていない | NG | c004 の center を [0.5, 0.35] |
| 2 | 全体 | C-1 冒頭のフック | OK | |
```

判定は OK / NG / 不明 のどれか。**不明は人に聞く項目**として E7 の試聴で確かめてもらう。
画像で判断できないもの（音・動き）を OK にしない。

## A. 素材を読む（E3 の前、文字起こしで）

| # | 項目 | 見方 |
|---|---|---|
| A-1 | 話の筋 | 文字起こしを通読し、話題の区切りを3〜7個に分けて書き出せるか。書き出せない部分は脱線か言い直しの候補 |
| A-2 | フックの候補 | 結論・一番具体的な数字・完成形を示す一言が、どの区間にあるか |
| A-3 | 削る候補 | 同じ説明の繰り返し、言い直し（直前の文をもう一度言っている）、本題と関係の薄い脱線 |
| A-4 | B ロールの候補 | 名前・数字・手順・場所・「これ」「ここ」など、画で見せた方が早い言葉の位置 |

## B. 境目の画像（sheet_NN.png、1行が1つの境目。左が直前、右が直後）

各行（境目）ごとに当てる。

| # | 項目 | NG の例 |
|---|---|---|
| B-1 | ジャンプカットが目立たない | 左右でほぼ同じ構図なのに人物の位置・姿勢が少しだけずれている（パンチインの差が足りない） |
| B-2 | 拡大で大事なものが切れていない | パンチインで頭頂・あご・画面録画のメニューが画面外に出ている |
| B-3 | 視線の流れ | 左で注目点（顔・カーソル・動くもの）が画面の右端、右で左端にあり、目が大きく飛ぶ（ショート動画では特に重い） |
| B-4 | B ロールの内容が話と合っている | 入りの行の字幕と、B ロールの画の内容が別のことを言っている |
| B-5 | B ロールの画質 | 引き伸ばしでぼけている、黒帯が出ている、透かし・他社のロゴが入っている |
| B-6 | 字幕の位置 | 字幕が顔・画面録画の操作部分・B ロールの文字に重なっている |
| B-7 | 画面の向き | 人物や動くものの向きが境目で逆になり、別の場所に見える（180度ルール） |

## C. 全体（EDL・SRT・check.py の出力から）

| # | 項目 | 見方 |
|---|---|---|
| C-1 | 冒頭のフック | 最初のクリップ（〜15秒）が、この動画で何が得られるかを示しているか。挨拶だけで始まっていないか |
| C-2 | 緩急 | クリップの長さの一覧（EDL から計算）が全部同じような長さになっていないか。説明は長め、列挙は短めか |
| C-3 | 削りすぎ | 削った区間の一覧を見て、話の筋（A-1）の一部が丸ごと消えていないか |
| C-4 | わざと残した間 | `note` に理由を書いた間が、ほかの詰めた境目と区別できているか |
| C-5 | 字幕の文言 | SRT を通読し、誤変換・固有名詞・数字の誤りが無いか。文字起こしのままの「えー」が残っていないか |
| C-6 | 締め | 最後のクリップが話の途中で終わっていないか。BGM のフェードアウトと合っているか |

## D. 人に聞く項目（E7 の試聴で）

エージェントは動画を再生して聞けないので、次は必ず人に確かめてもらう。`review.md` に「不明」で残し、試聴の依頼に並べる。

- 声と BGM の大きさの釣り合い、声の聞き取りやすさ
- 境目での音の跳ね（部屋の雑音の急な変化、息の途切れ）
- 詰めすぎて息苦しい区間、間延びした区間
- J/L カットで口の動きと声がずれて見えないか
- 感情（Murch の原則1）: 間を詰めたことで、笑い・驚き・重い話の余韻が消えていないか
