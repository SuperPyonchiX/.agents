# 確認シートで回す実機確認

エージェントが動かせない環境での確認は、ユーザー（またはテスター）との往復になる。シートの書き方や NG の切り分けは任せてよい。このスキルが縛るのは**往復の回し方**である。失敗しやすいのは (1) 起動すら通らないビルドで長い本体を流させる、(2) OK だった行を毎回確かめ直させる、(3) 結果に合わせて期待結果を書き換える・残件を黙って保留にする、の3つ。

## ワークフロー

```
M0 対象・実行者・環境・形式（会話なら Markdown、Excel 等なら CSV）を確定。読み取れないものだけ尋ねる
M1 シート作成 work/test-sheet-r1.md
for 回 in 1..4:
    M2 依頼
    M3 集計（sheet.py summary）。終了コード0なら break
    M4 NG の切り分けと修正
    M5 次の回を切り出す（sheet.py next）
else:
    4回で完了しない → 残りの NG と試したことを報告して止まる
M6 完了報告
```

## 手順

### M1: シート作成

`assets/templates/test-sheet.md` を `work/test-sheet-r1.md` にコピーして行を書く。CSV なら列は `ID,区分,確認すること,手順,期待結果,結果,メモ`。

- **S-（スモーク）** 1〜3件。数分で終わり、落ちれば本体が無意味になるもの（起動・最初の操作・最小の入力）。毎回載る
- **T-（本体）** 1行1件。まとめてよいのは同じ手順で続けて見られるものだけ
- **R-（回帰）** 以前直した不具合のうち今回の変更で壊れうるものの最小セット。毎回載る
- 期待結果は観察できる形で書く（「正しく動く」ではなく「応答メッセージが1本追加され、Output に例外が出ない」）

**完了条件**: `python scripts/sheet.py summary work/test-sheet-r1.md` が終了コード 0 か 1 であること。

### M2: 依頼

シート（ファイルならパス）を提示し、**スモークを先に実行して1件でも NG ならそこで返す**ことを明記する。一括確認が30分を超えるなら、スモークの後でいったん返してもらう。2回目以降は、載っているのがスモーク・回帰と前回の NG・未実施・未記入だけであることを添える。

### M3: 集計

会話で受け取った結果はエージェントが結果欄とメモ欄に写す（画像は ID と対応づけてメモに書く）。`python scripts/sheet.py summary <シート>` を実行し、件数をユーザーに1行で示す。終了コード 0 なら M6、1 なら M4（`smoke_ng` があればスモークの NG だけを先に扱う）、2 なら表示された箇所を直して再実行する。

### M4: NG の切り分けと修正

- 1回分の結果をまとめて受け取ってから直す。同じ原因の NG は1回で直す
- 原因が**シートの誤り**（期待結果・手順の間違い）なら、直した内容と理由を示して了承を得てから直す
- 原因が環境・情報不足なら、整える手順や見るべきログの場所を次の回の手順に足す
- **同じ ID が2回続けて NG なら**同じ直し方を繰り返さず、前提を疑って仮説を立て直す
- 未実施・未記入は理由を聞く。前提が満たせないなら手順を直す
- 保留にしてよいかはユーザーに確認し、了承を得た行だけ結果を「保留」にしてメモに理由を書く

**完了条件**: 全 NG 行に原因と対応が付き、実装の不具合は修正済みであること。

### M5: 次の回を切り出す

修正の影響で既存の OK 項目が壊れうるなら、理由と元の ID をメモに書いた R- 行として r<N> に追加してから切り出す。影響のない OK 項目は戻さない。

```
python scripts/sheet.py next work/test-sheet-r<N>.md -o work/test-sheet-r<N+1>.md --round <N+1>
```

前回のシートは消さずに残す。M4 で直したシートの誤りが新しいシートに反映されていることを確かめ、M2 に戻る。

### M6: 完了報告

回数と最終の集計、保留にした行と理由（了承を得た旨）、途中で直したシートの誤り、確認していない範囲（載せなかった条件・環境）を提示する。都合の悪い項目を省かない。

## 禁止事項

- **スモークが NG のまま本体を依頼すること。**
- **本体の OK の行を次の回に載せること。** `sheet.py next` を使わずに手で切り出さない。
- **期待結果を、受け取った結果に合わせて黙って書き換えること。**
- **ユーザーの了承なしに保留にすること。**
- **確認結果を受け取っていないのに「完了」と報告すること。**
- **NG が1件出るたびに1件ずつ往復すること。**

## スクリプト

`scripts/sheet.py` — M1・M3・M5 で使う。依存は標準ライブラリのみ。

```
python scripts/sheet.py summary <sheet>
python scripts/sheet.py next <sheet> -o <次の回のシート> [--round N]
```

| サブコマンド | 動作 |
|---|---|
| `summary` | 件数、NG・未実施・未記入・保留の ID、スモークの NG（`smoke_ng`）、完了か（`done`）を JSON で出す |
| `next` | S- と R- の全行、NG・未実施・未記入の本体の行を、結果を空にして書き出す。前回のメモは「前回: 」付きで残す。出力の拡張子で Markdown か CSV かを決める。Markdown 同士なら表より前の説明文（対象・環境・返し方・スモーク先行の注記）も引き継ぎ、見出しの回数を `--round` に書き換える。CSV には説明文が入らないので、M2 の依頼文で伝える |

シートは Markdown の表（最初に `ID` と `結果` の列を持つ表）か CSV（UTF-8、BOM 付き可）。7列すべて必須。結果欄は OK / NG / 未実施 / 保留 / 空欄のどれか。

| 終了コード | summary | next |
|---|---|---|
| 0 | 全行が OK か保留（完了） | 書き出した |
| 1 | NG・未実施・未記入が残っている | NG・未実施・未記入が0件（完了済み。書き出さない） |
| 2 | 引数の指定ミス、表が無い、列が足りない、ID の重複、結果欄の値が不正 | 同左 |
