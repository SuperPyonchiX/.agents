# 概要

| 項目 | 内容 |
|---|---|
| 成果物 | 〔何ができたか。1行〕 |
| 使ったAI・モデル | 〔Claude Code / ChatGPT など。モデル名まで分かれば書く〕 |
| 所要 | 〔30分 / 半日 など。分からなければ「不明」と書く〕 |
| 日付 | 〔YYYY-MM-DD〕 |

〔何を解決したかったのかを1〜2文。前提条件（対象リポジトリ、扱ったファイル、制約）もここに書く〕

# やったこと

〔再現に必要な手数だけを時系列で並べる。試行錯誤の全記録にしない。
  各項目は「何を指示したか（狙い）」→「どうなったか」の形で1〜3行に収める〕

1. 〔投げた指示の要点〕（狙い: 〔なぜそう指示したか〕）
   → 〔返ってきたもの、または不足していた点〕
2. 〔次の指示〕
   → 〔結果〕
3. 〔以降同様。目安5〜8手。超えるなら件を分割する〕

# 効いたポイント

〔3〜6個。各項目に必ず理由を添える。
  この作業をやらなくても言える一般論は書かない〕

- **〔効いた具体的な打ち手〕** — 理由: 〔なぜ効いたか。効かなかったときとの差〕
- **〔同上〕** — 理由: 〔同上〕
- **〔同上〕** — 理由: 〔同上〕

# つまずいたこと・避けること

〔次回避けるべきものだけを残す。解決済みの些末な失敗は書かない〕

- 〔やってしまったこと〕→ 〔どうなったか / 代わりにどうするか〕
